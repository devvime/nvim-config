# Nvim config

Configurações do Neovim.

### Instalação

Clone este repositório na pasta /home/user-name/.config/nvim

### Instalar fonte

```bash
mkdir -p ~/.local/share/fonts
cd ~/.local/share/fonts

wget https://github.com/ryanoasis/nerd-fonts/releases/latest/download/JetBrainsMono.zip
unzip JetBrainsMono.zip
fc-cache -fv
```

### Configurar o terminal

```bash
Preferences → Profile → Text
☑ Custom font
→ JetBrainsMono Nerd Font Regular
```
